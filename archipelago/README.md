# The Archipelago

The portfolio of **Sumanth Richie** (Amidyala Sai Sumanth), designer, 3D artist and creative developer in Hyderabad,
built from *Bible 02 — The Archipelago*.

Four islands of work float over a sea of cloud in a midnight-indigo sky. Scrolling sails between them, from night to
dawn, and every work is a physical thing on an island, never a card floating in space:

| # | Island | What is there | Works |
|---|--------|---------------|-------|
| 01 | **Worlds** | A temple and pagoda over a koi pond lit from below, twelve koi; the real Ring Gate citadel half-drowned in a sea pool; the Flooded Rotunda's twelve arches; the Fudō shrine with one candle; the castle on its crag; the Overgrown Archive's lantern path | Ring Gate, Flooded Rotunda, Overgrown Archive, Castle on the Crag, Koi Pond, Fudō Myō-ō, Rōman no Yoake, Caves |
| 02 | **Machines** | A banked circuit with a standing Möbius loop, light trails, lamp posts and Hangar 7. Hyperion GEN.2 and the Alpine F1 race (chase camera, lap timer), then park: Hyperion on a turntable, the F1 exploded on a lift, the Koenigsegg from Coachwork split half paint, half wire; the Vanta helmet in the hangar | Hyperion, Hyperion Case Study, Alpine F1, Coachwork, Vanta |
| 03 | **Monuments** | A white marble quarry. The Parian head, colossal, with gold kintsugi that lights as it turns; Halden's field camera on its tripod taking the head's portrait; the Altair road spiralling down the cliff with **2,141** lamps and **808** trees to the monolith | Parian, Halden, Altair Estates, sculpting, clock, extinguisher, interiors |
| 04 | **Brands** | A tower you climb floor by floor: GC Burger's diner and the plaza billboards, KERB's pit terrace, Deccan Night Run's arcade, Lotus's half-built wing under a crane, REM's after-hours floor, CapQ's glass atrium, Mitti and Maruneta on the clay floor, the signal floor (BSNL, Rujuvu, Kosh, LAGRANGE), the molten Magma core, and Photon Yard's beacon in the crown | 19 brand works, 9 of them new and unposted |

Then the whole archipelago flattens into **the Map**: a gold-ink chart with contour lines, the voyage route, a pin
for every work and a legend you can click. The camera dives through the cloud to a calm sea at dawn, and a
**lighthouse** beam comes to rest on the email address.

## Run it

```bash
npm install
npm run dev          # writes the static pages, then http://localhost:5173
npm run build        # pages + type-check + production build into dist/
npm run preview
```

URL flags: `?q=1|2|3` forces a quality tier, `?skipintro` skips the preloader, `?static` shows the page version,
`?vh=1296` starts at a point on the voyage, `?to=<slug>` flies to a work, `#<slug>` opens its panel.

Keys: **1–4** fly to an island, **M** the map, **L** list view, **S** sound, **Esc** closes, **← →** step through works.

## How it is built

- **Vite + TypeScript + three.js**, no framework. `postprocessing` for bloom, ACES, vignette, grain and chromatic
  aberration (with an HDR sanitise pass first, so one bad pixel can never black out the bloom chain).
- **Lenis** smooth scroll drives a keyframed camera rig (`src/core/voyage.ts`): Catmull-Rom between keys, and segments
  that orbit the tower in cylindrical coordinates so the climb never cuts through it. Portrait screens get a wider
  lens and a dolly back so phones keep the desktop framing.
- **GSAP** for the type: chapter titles letter by letter, pull lines word by word, the menu.
- **Everything is procedural or real.** The sky (stars, Milky Way, moon, dawn), the cloud sea, the islands, the koi,
  the tower, the lava and the Gerstner sea are generated in code. The cars, the head, the camera, the helmet and the
  Ring Gate are Sumanth's own production models.
- **Sound** is synthesised with Web Audio (no audio files): a wind bed in D, water and frogs, track hiss and an engine
  that follows the race, a city hum, a magma roar, the sea, a foghorn. Off until the visitor opts in.
- **Chart mode** is one uniform (`G.uChart`) every world material reads: surfaces turn to ink with gold iso-height
  contour lines, so the map is the real geometry, not a drawing of it.

## Adding a work

1. Add it to `src/data/works.json` (`island`, `title`, `line`, `tools`, `live`, `brief`, `facts`, `isNew`).
2. Add its images to `IMAGES` in `scripts/build-assets.mjs` and run `SU3_REPOS=… DRIVE=… node scripts/build-assets.mjs images`.
3. To put it on the voyage, add its slug to a beat's `works` in `src/core/story.ts` and give it an artefact in the
   island's file (a framed print, a room in the tower, a model).

## Performance and fallbacks

- Three tiers from the GPU string (motes 26k / 14k / 6k, cloud layers 8 / 6 / 4, tessellation, MSAA or SMAA), and a
  frame governor that lowers resolution if frames run long.
- Island contents are culled by distance; models are meshopt or Draco compressed with WebP textures
  (Hyperion 10.3 → 5.8 MB, F1 7.6 → 4.4 MB, Agera 2.0 → 1.1 MB). JS is 340 KB gzipped.
- No WebGL2, Save-Data or `?static`: the same page shows the full portfolio as HTML. Every work also has its own
  static case-study page, so nothing is locked inside the canvas. `prefers-reduced-motion` and the menu's Calm mode
  turn off smoothing, flights and drift.
