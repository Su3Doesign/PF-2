Deccan Night Run

🔒 Live site coming soon The full presentation ↓ See it on the voyage All work

A city night run where the arches keep time: arch, minaret, lamp.

At midnight the old city slows down to a sequence of arches. Deccan Night Run turns that rhythm into an event with no podium and no rush: a logo built from arch, minaret and lamp, a sodium-on-midnight palette, race kits, route wayfinding and a pocket app.

Concept project. Fictional brand, no affiliation.
